Key definitions

Key definitions

  • Linear scan — visit items one by one until the target or the end; O(n) always, but works on ANY sequence.
  • Early exit — stop scanning the moment the answer is known - found it, or proved nothing ahead can match.
  • Sentinel value — a reserved answer (-1, None) meaning 'not found'; must be impossible to confuse with a real result.
  • Filter — a scan that collects all matches instead of the first - the accumulator list applied to search.
  • Precondition — a promise about the input (e.g. 'sorted', 'two runs') that a faster method may rely on.
  • Best/worst case — the same algorithm has a cost range; the target's position decides which you get.
Explain each in one breath; the cases will do the heavy lifting.
Worked example

Find the First Freeze: scan with early exit

cs-065

Daily temperatures are 12, 8, 3, -1, -4, 2 degrees. On which day index does the first freeze (temperature at or below 0) occur?

temps = [12, 8, 3, -1, -4, 2]
idx = None
for i, t in enumerate(temps):
    if t <= 0:
        idx = i
        break
print(idx, temps[idx])

Expected: first freeze at index 3 (temperature -1)

Cost: O(n) worst case, but best case O(1) when the freeze is early; early exit is free - take it.

Worked example

The Course Finder: linear search on an unsorted catalogue

cs-066

A catalogue holds (code, title) pairs in no particular order. Find the title for code 'DS2', and define the behaviour for an unknown code.

catalogue = [("CS1", "Problem Solving"), ("DS2", "Statistics"), ("CS3", "Systems")]

def find(code):
    for c, title in catalogue:
        if c == code:
            return title
    return "not offered"

print(find("DS2"), find("XX9"))

Expected: Statistics / not offered

Cost: O(n) time, O(1) space; already optimal for unsorted input.

Worked example

Peak Finding: the first descent marks a peak

cs-068

In the values 1, 3, 8, 4, 2 find a peak - a value at least as large as its neighbours.

a = [1, 3, 8, 4, 2]
peak = None
for i in range(len(a) - 1):
    if a[i] >= a[i + 1]:
        peak = i
        break
if peak is None:
    peak = len(a) - 1
print(a[peak])

Expected: a peak is 8 (at index 2)

Cost: O(n) here; lecture 21 revisits this problem with binary search for O(log n) - a first taste of the same problem having algorithms of different cost.

Check yourself

Common misconceptions

  • Returning the loop index 0 as 'not found' - zero is a legitimate position; use None or -1 by spec.
  • Breaking early without justification on multi-match scans.
  • Assuming linear scan is 'the dumb way' - on unsorted data it is the ONLY way.
  • Confusing best case with typical case when reasoning about cost.
