Key definitions

Key definitions

  • Running total — a variable updated inside a loop so its final value summarises the whole sequence.
  • Count — a running total restricted to items meeting a condition.
  • Min / Max / Argmax — the smallest/largest value; argmax is the *position or key* of the maximum.
  • Streak — the number of consecutive items meeting a condition; state resets on a miss.
  • Window (k-slice) — the sum/aggregate of k consecutive items; the window slides one step at a time.
  • Two-pass thinking — first compute an intermediate aggregate (e.g. total), then answer the real question from it.
Explain each in one breath; the cases will do the heavy lifting.
Worked example

The reading log: one pass, four aggregates

cs-033

Pages [12, 0, 25, 8, 30], target 10. Report total, average, best day, and how many days fell below target.

Expected: {'total': 75, 'avg': 15.0, 'best': 30, 'below': 2}

Cost: O(n) time, O(1) space - four aggregates for the price of one loop.

Worked example

Stockroom spikes: argmax with witnesses

cs-034

Sales [100, 210, 205, 420, 90]. A day is a spike if it beats both neighbours. Reference answer: [1, 3].

Expected: [1, 3]

Cost: O(n) time, O(1) extra space (output excluded).

Worked example

The longest streak: reset vs stop

cs-035

Goals met [1, 1, 0, 1, 1, 1, 0, 1]. Longest streak of consecutive met goals - plus two zero cases: end-on-a-miss, and all-miss.

Expected: best 3 | end-current 0 in the reference's variant | all-miss 0

Cost: O(n) time, O(1) space - the two-variable discipline is the whole lesson.

Worked example

Rainfall windows: the slide

cs-036

Rain [3, 5, 2, 8, 1, 4], window k = 3. The reference prints [5, 8, 8, 8] - derive what question it actually answers before trusting the prose.

pages = [12, 0, 25, 8, 30]
target = 10
total = sum(pages)
best = max(pages)
below = sum(1 for p in pages if p < target)
print(total, total / len(pages), best, below)

Expected: sums [10, 15, 11, 13]; maxima [5, 8, 8, 8] (the reference's question)

Cost: O(n) slide vs O(n*k) recomputed - the analysis teaser for Block III.

Check yourself

Common misconceptions

  • Recomputing totals inside the loop instead of maintaining them.
  • Forgetting to reset streak state after a miss.
  • Confusing max with argmax - the value versus its position.
  • Sliding windows by recomputing each sum from scratch and calling it 'fine'.
