Key definitions

Key definitions

  • Simulation — running a model many times with randomness to observe the range of outcomes
  • Random seed — the starting point of the pseudo-random stream; fixed seeds make runs reproducible
  • Trial — one run of the model; a simulation is many trials
  • Estimate — a trial-derived approximation of a theoretical quantity
  • Standard error — how far the estimate typically wobbles; shrinks like 1/sqrt(trials)
  • Validation — checking a simulation against a case with a known answer before trusting it
Explain each in one breath; the cases will do the heavy lifting.
Worked example

Dice Before Data: from model to simulation

cs-113

Two fair dice. Estimate P(sum = 8) by enumeration and by simulation; compare with the exact 5/36.

import random
random.seed(7)
exact = sum(1 for a in range(1, 7) for b in range(1, 7) if a + b == 8) / 36
hits = sum(1 for _ in range(10000) if random.randint(1, 6) + random.randint(1, 6) == 8)
estimate = hits / 10000
print(round(exact, 4), round(estimate, 3))

Expected: exact 0.1389; simulated ~0.138 (seed 7, 10,000 trials)

Cost: O(trials); standard error shrinks as 1/sqrt(trials) - four times the trials buy two times the precision.

Worked example

The Queue Waiting Game: simulate, then sanity-check

cs-114

One server, arrivals every 2 minutes, service takes exactly 1 minute. Simulate 10 customers; what is the maximum wait, and does that match the analytical answer (0)?

free = 0
worst = 0
for i in range(10):
    arrival = 2 * i
    start = max(arrival, free)
    worst = max(worst, start - arrival)
    free = start + 1
print(worst)

Expected: maximum wait: 0 minutes (matches the analytical answer)

Cost: O(customers); the analytical check cost nothing and caught nothing - which is the point of running it.

Worked example

The Exam Gambler: simulation answers what algebra cannot

cs-115

A quiz: answer 4-option questions, 0.25 penalty per wrong answer. Strategy A: answer everything. Strategy B: answer only if you can eliminate one option. Estimate expected scores per question.

import random
random.seed(11)
N = 100000
score_a = score_b = 0
for _ in range(N):
    score_a += 1 if random.random() < 0.25 else -0.25
    score_b += 1 if random.random() < 1 / 3 else -0.25
print(round(score_a / N, 4), round(score_b / N, 4))

Expected: expected score per question: A ~ 0.0625, B ~ 0.167

Cost: O(N) per strategy; precision 1/sqrt(N) as always.

The Buffon Needle

Check yourself

Common misconceptions

  • Reporting a simulation without its seed or trial count - not reproducible, not a result.
  • Assuming more trials help proportionally - standard error shrinks like 1/sqrt(trials).
  • Trusting a model that was never run against a known-answer case.
  • Confusing one unlucky trial with a bad model - look at the distribution, not one run.
