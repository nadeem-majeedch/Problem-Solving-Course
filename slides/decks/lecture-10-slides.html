Key definitions

Key definitions

  • String — an immutable sequence of characters; every 'change' builds a new string.
  • Indexing — s[0] is the first character; s[-1] the last; out-of-range is an error.
  • Slicing — s[a:b] is characters a..b-1; the end is exclusive; s[::-1] reverses.
  • Normalisation — putting strings into a canonical form (case, spacing, order) before comparison.
  • Parsing — turning one structured string into pieces (split on separators, strip noise).
  • Character class — a test like isdigit/isalpha/isspace applied per character.
Explain each in one breath; the cases will do the heavy lifting.
Worked example

Username auditor: classifier with one character of memory

cs-037

Usernames valid when: 5-16 chars, letters/digits/underscores only, not starting with a digit, no two consecutive underscores. Audit the batch.

Expected: pass | fail: consecutive underscores | fail: starts with letter check | fail: too short

Cost: O(length) with early exits; the design content is the rule ORDER.

Worked example

The reversal family: three problems, one idea

cs-038

Reverse 'stressed' → 'desserts'; reverse words of 'the quick brown fox'; decide whether 'Never odd or even' is a palindrome.

Expected: desserts | fox brown quick the | True False

Cost: O(n) per operation; lecture 19 replaces slicing with two pointers for the palindrome.

Worked example

Template mail-merge: parse, fill, report

cs-039

Template 'Dear {name}, your {item} is due {deadline}.' When 'item' is missing, print '[item]' visibly rather than crashing.

Expected: Dear Ada, your [item] is due Friday. | Dear Bo, your book is due Monday.

Cost: O(template + record); accumulate-then-join, not repeated concatenation.

Worked example

The anagram detector: the normalisation ladder

cs-040

'Dormitory' / 'dirty room!'; 'astronomer' / 'moon starer'; 'hello' / 'world'. Reference: True, True, False.

for name in ("ab1", "abc"):
    print(name, name[0].isalpha() and name[-1].isdigit())

Expected: True | True | False

Cost: O(n log n) via sorting; counting is O(n) - both honest, the ladder is the transferable part.

Check yourself

Common misconceptions

  • Comparing strings before normalising case and spaces.
  • Trying to mutate strings in place - immutability surprise.
  • Off-by-one in slices: the end boundary is exclusive.
  • Parsing with hand-managed indexes when split/join states the intent.
