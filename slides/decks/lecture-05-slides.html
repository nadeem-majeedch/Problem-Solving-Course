Key definitions

Key definitions

  • Integer division `//` — division keeping only the whole part: `17 // 5` is 3.
  • Remainder (modulo) `%` — what is left after whole divisions: `17 % 5` is 2.
  • Cycle — a pattern repeating every k steps; `n % k` names the position inside the cycle.
  • Digit extraction — `n % 10` is the last digit of n; `n // 10` removes it.
  • Divisor — d divides n exactly when `n % d == 0`.
  • Simulation — stepping a process rule by rule, as it would happen, instead of computing a formula.
Explain each in one breath; the cases will do the heavy lifting.
Worked example

The pager schedule as a cycle

cs-017

On-call duty rotates among 5 people daily; person 1 is on call on day 1. Who is on call on day 47? And what changes if rotation skips weekends (day 1 = Monday)?

Expected: 2 then 5

Cost: O(1) for both variants - arithmetic beats simulating day by day.

Worked example

Digits, sums, and the divisible-by-3 rule

cs-018

Peel the digits of 4723 by arithmetic and sum them. Is 4723 divisible by 3?

n = 4723
total = 0
while n > 0:
    total += n % 10
    n //= 10
print(total)

Expected: 16 then False

Cost: O(d) where d is the digit count (about log10 of n) - logarithmic in the value, which surprises students.

Case cs-017 · Beginner

The Pager Schedule

On-call duty rotates among 5 people every day. Given the day number of the year and who starts, decide who is on call. Then: what changes if rotation skips weekends?

  • **Input:** 5 people, rotation starts with person 1 on day 1; day 47
  • **Output:** day 47 -> ((47-1) mod 5)+1 = person 2; with weekend skip: count only weekdays
  • Solve for the worked instance first. Then ask what would change if one
  • number, name, or condition were replaced by something stranger.

Check yourself

Common misconceptions

  • Treating % as trivia to memorise instead of a cycle-position tool.
  • Starting cycles at 1 vs 0 - state the convention before computing.
  • Extracting digits with strings when the arithmetic is the point of the exercise.
  • Simulating the Josephus ring for large n instead of tabulating small cases and finding the pattern.
