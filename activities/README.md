# In-Class Activities

Short, no-preparation classroom routines used inside the 2-hour lectures.
Each is a repeatable format rather than a one-off — run them with any
case study. Instructors: timings and pitfalls are in the linked notes.

| Activity | Format | Time | Used in |
| --- | --- | --- | --- |
| [Think-Pair-Debug](think-pair-debug.md) | Debug a 6-line snippet | 8 min | any lecture from 05 |
| [Case Relay](case-relay.md) | Teams each solve one step | 12 min | lectures 09–20 |
| [Sketch That Flow](sketch-that-flow.md) | Flowchart under time pressure | 7 min | lectures 01–04, 17 |
| [Complexity Duel](complexity-duel.md) | Rank snippets by cost | 6 min | lectures 17–24 |

Enrichment, not assessment: none of these are graded.
