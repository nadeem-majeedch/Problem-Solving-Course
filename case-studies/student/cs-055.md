## Problem

A function with a mutable default argument accumulates state across calls. Diagnose, fix, and generalise the lesson to API design.

Your deliverable is the function list with contracts, the composed driver, and one input per function that exercises its edge. If the problem is ambiguous anywhere,
state the assumption you are making and carry on — a stated assumption is
part of a good answer.

## Examples

- **Input:** def add_tag(tag, tags=[]): called three times
- **Output:** the default list persists: calls accumulate; fix: None sentinel + fresh list

Solve for the worked instance first. Then ask what would change if one
number, name, or condition were replaced by something stranger.

## What to notice

- Defaults are evaluated ONCE at definition. Print id(tags) across calls to watch it stay the same.
- A good function name is a miniature specification.
- Return values compose; printed output does not.

## Discussion starter

After the solution is revealed, the class spends five minutes on this
prompt: **"Where would this decomposition crack if the input format changed?"**
