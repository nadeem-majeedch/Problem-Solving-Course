## Problem

A keypad digit is dead; given a target number, output all numbers up to N that avoid that digit. Careful digit checking with // and %.

Your deliverable is the stated assumptions, the digit-replacement rule, the rewritten number for the worked instance, and one boundary value (all digits affected, or none) traced. If the problem is ambiguous anywhere,
state the assumption you are making and carry on — a stated assumption is
part of a good answer.

## Examples

- **Input:** dead digit 4, N = 30
- **Output:** 1,2,3,5,6,7,8,9,10,11,12,13,15,... (23 numbers below 30 avoid the digit 4)

Solve for the worked instance first. Then ask what would change if one
number, name, or condition were replaced by something stranger.

## What to notice

- Two ways: check str(d) for the dead digit, or peel digits with % and // - implement both, compare.
- Writing the rules IS the solution; code is transcription.
- Every assumption is a place where two good answers can differ.

## Discussion starter

After the solution is revealed, the class spends five minutes on this
prompt: **"Propose one extra rule that would change the verdict — is it an improvement?"**
