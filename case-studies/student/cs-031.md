## Problem

Given a small function with tricky internal branches, compare the tests a black-box tester writes with the tests the code's structure demands. Which defect escapes which suite?

Your deliverable is the complete test table with expected outputs, the boundary rationale, and the automated run result. If the problem is ambiguous anywhere,
state the assumption you are making and carry on — a stated assumption is
part of a good answer.

## Examples

- **Input:** def fee(x): if x < 3: return 0; elif x <= 5: return 2; else: return 5
- **Output:** black-box misses x=3 exactly (0 vs 2 boundary) and negative x; white-box adds both; the escaped defect is 'x < 3' vs 'x <= 3'

Solve for the worked instance first. Then ask what would change if one
number, name, or condition were replaced by something stranger.

## What to notice

- Enumerate branch outcomes first, then ask which inputs force each branch.
- A test case is a falsifiable claim about the requirement.
- Boundaries are where specifications and implementations disagree.

## Discussion starter

After the solution is revealed, the class spends five minutes on this
prompt: **"What would a 'suite' that can never fail tell you about its tests?"**
