## Reasoning walkthrough

**Worked instance.** Eleven slips naming Zoe, Amir, Bea, or Cal; report
the tally, the winner, and shares without over-claiming.

**Expected result.** demo prints `tally {'Zoe': 4, 'Amir': 3, 'Bea':
2, 'Cal': 2}` and `winner Zoe 4/11 = 36.4% | runner-up Amir 3/11 =
27.3%` — a plurality, not a majority: 36.4% is most slips but well
under half, which is exactly what the announcement sentence must not
blur.

**Method — aggregation, communication, data.** Walk the class through
these moves:

1. One pass, one running number per name — the tally *is* an
   aggregation pattern (lecture-09's dictionary habit in embryo).
2. Name the rule that crowns the winner: "most slips" (plurality).
   Under a majority rule the same slips produce *no* winner — the
   rule is part of the result, not background.
3. Percentages name their base: 4/11 and 3/11, of valid ballots, to
   one decimal. "40%" or "most of the room" are the errors to catch.
4. The honest sentence: report the count and the share, and what the
   data cannot say (the absent twelfth member, second choices).

**Where this class gets stuck.** Beginners finish at the tally and
announce "Zoe wins!" — the over-claim is the teaching target, not a
footnote. Second stall: computing 4/11 as 0.3636… and rounding to
"36%" with no base named; ask "36 of what?" until the base habit
forms.

## Five-minute teaching sequence

Minute 0–1 — **Read and analyse.** Expect the four names and the
ballot count identified. Watch for: counting by candidate with four
separate passes (fine, but say why one pass scales).
Minute 1–3 — **Develop an approach.** Expect the tally 4/3/2/2; a
correct tally with a missing rule statement is partial credit.
Watch for: "Zoe has the most" written as "Zoe wins".
Minute 3–5 — **Compare and write.** Expect the percentages with bases
and the announcement sentence drafted; pairs test each sentence for
over-claim.
Reveal and discuss — keep the reveal inside 10 minutes so the exit question still fits.

## Difficulty adaptation

- **Simplify.** Six slips, two candidates; ask for tally and one
  honest sentence.
- **Extend.** The runoff extension: what data would the ballots need
  to carry (second choices) for the chair's proposal to work?
- **Hints (progressive).**
  1. *Re-orient:* "Count in one pass, keeping one running number per
     name."
  2. *Structure:* "Tally, then rule, then shares with bases, then
     the sentence."
  3. *Near-answer:* the common wrong turn is 'Zoe wins by a
     landslide' — undo that phrasing and re-derive what 4/11
     licenses.

## Reference solution (pseudocode)

```
tally <- empty map
FOR EACH slip IN slips: tally[slip] <- tally[slip] + 1
order <- tally sorted by count (desc), name (asc)
winner, runner <- order[0], order[1]
OUTPUT tally, winner and runner with shares of len(slips)
```

## Reference solution (Python)

```python
SLIPS = ["Zoe", "Amir", "Zoe", "Bea", "Amir", "Cal", "Zoe",
         "Bea", "Cal", "Amir", "Zoe"]

if __name__ == "__main__":
    tally = {}
    for s in SLIPS:
        tally[s] = tally.get(s, 0) + 1
    order = sorted(tally.items(), key=lambda kv: (-kv[1], kv[0]))
    (winner, w), (runner, r) = order[0], order[1]
    n = len(SLIPS)
    print("tally", dict(order))
    print(f"winner {winner} {w}/{n} = {100 * w / n:.1f}% | "
          f"runner-up {runner} {r}/{n} = {100 * r / n:.1f}%")
```

The code is runnable as-is; executing the file prints the worked instance
so you can demo it live on the projector.

## Edge cases

- A tie for winner — the rule must define the tie-break or the
  announcement cannot be written; this instance avoids it, the
  question must not.
- A blank or illegible slip — the valid-ballot denominator changes;
  count it and say so.
- One candidate receiving all slips — 100.0% is honest; "unanimous"
  is the sentence the rule licenses.

## Alternative approaches

- Four hand tallies (one per candidate) — perfectly good at n = 11;
  the dictionary form scales and previews lecture-13.
- Sorted list + run-length counting — same result via sorting;
  useful contrast when slips arrive already alphabetised.
- Reporting counts without percentages — honest and often enough;
  percentages earn their place only when shares are compared.
- **Cost.** One pass, O(n) with a constant map; every variant here is
  linear — the differences are auditability and growth.

## Common pitfalls

- Announcing a winner without naming the rule (plurality).
- Percentages without their base, or rounded to hide the small n.
- Treating 36.4% as "most students want Zoe" — eleven slips are not
  the students.
- Losing a slip in the tally (count the slips after: 11).

## Reveal script

1. Display the case and start the timer (5 minutes). While students work,
   circulate and read shoulders; pick one conventional attempt and one
   surprising one for the board.
2. Ask first: "What rule turns these slips into a winner?"
3. Build the tally on the board in one pass, the room calling each
   update.
4. Surface the wrong turn directly: the landslide sentence — ask what
   4/11 cannot say.
5. Show the reference Python, run it on the worked instance, and let the
   class compare with their own answers.
6. Close by naming the technique — "tally, rule, share, sentence" —
   and hand over the discussion prompt about the runoff.

## Assessment use

- **Formative use.** discussion-grade: mark the honesty of the
  sentence over the tally's correctness.
- **Mini-rubric (10 points).**
  - *Structure (2):* tally complete and checkable (sums to 11).
  - *Method (3):* winner rule named; percentages carry bases.
  - *Result (3):* 4/3/2/2, 36.4% vs 27.3%, correct runner-up.
  - *Communication (2):* sentence reports without over-claiming.
- **Follow-up check.** One slip is spoiled: which numbers change, and
  does the winner?
