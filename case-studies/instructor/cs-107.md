## Reference solution (pseudocode)

FUNCTION norm_id(sid)
    RETURN ((TEXT(sid) stripped) lowercased)
FUNCTION norm_name(name)
    parts <- (((name stripped) lowercased) split into words)
    RETURN TUPLE({p for each p in parts AND p})
FUNCTION same_student(a, b)
    IF (a[1]) AND (b[1]) AND (norm_id(a[1]) = norm_id(b[1])) THEN
        RETURN 'id'
    (na, nb) <- (norm_name(a[0]), norm_name(b[0]))
    IF (na[-1] = nb[-1]) AND ((na[0][0] = nb[0][0]) OR (na[0] = nb[0])) THEN
        RETURN 'name'
    RETURN null

## Reference solution (Python)

```python
def norm_id(sid):
    return str(sid).strip().lower()

def norm_name(name):
    parts = name.strip().lower().split()
    return tuple(p for p in parts if p)

def same_student(a, b):
    if a[1] and b[1] and norm_id(a[1]) == norm_id(b[1]):
        return "id"
    na, nb = norm_name(a[0]), norm_name(b[0])
    if na[-1] == nb[-1] and (na[0][0] == nb[0][0] or na[0] == nb[0]):
        return "name"
    return None

if __name__ == "__main__":
    print(same_student(("Ada Lovelace", "S2023-0471"), ("ada lovelace ", "s2023-0471 ")))
    print(same_student(("Ada Lovelace", "S2023-0471"), ("A. Lovelace", "S2023-9999")))
```

## Alternative approaches

- Design the rule in tiers: exact key match, normalised key match, fuzzy match, human queue - and report each tier's catch rate.
- Loop-first formulation versus a comprehension/direct-expression formulation — same result, different emphasis on state versus intent.
- An explicit stack or a plain loop instead of the recursion: identical visits, no call-stack growth.


## Common pitfalls

- Hiding a value judgement inside 'obvious' arithmetic.
- Reporting the answer without the rule that produced it — the decision becomes uncheckable.


## Reveal script

3. Walk the worked instance ("Ada Lovelace" / "ada lovelace" / "A. Lovelace" / id "S2023-0471" vs "s2023-0471 ") on the board

4. Surface the wrong turn directly: 'hiding a value judgement inside 'obvious' arithmetic' — ask the room

5. Show the reference Python, run it on the worked instance, and let the
   class compare with their own answers.
