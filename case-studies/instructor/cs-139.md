## Reasoning walkthrough

**Worked instance.** Two weeks of library visits; the second week lost
three days to a holiday; staff A blames the survey, staff B blames the
calendar.

**Expected result.** demo prints `totals 2600 vs 970 (-63%) |
per-open-day 520 vs 485 (-6.7%)` — both frames use the same numbers;
only the denominator changes, and only one frame answers "did demand
change?".

**Method — bias, evaluation, stakeholders.** Walk the class through
these moves:

1. Compute both frames before arguing: totals 2600 vs 970 (−62.7%);
   open days 5 vs 2, per-open-day 520 vs 485 (−6.7%). Two frames, one
   dataset, different stories.
2. Ask what question each frame answers: the total frame answers
   "how many visits did we serve?", the per-open-day frame answers
   "how busy was a typical open day?" — Staff A's causal story
   (survey → avoidance) is only testable by the second.
3. Verdict with a rule: when the calendar differs between periods,
   compare like-for-like denominators first; totals are reported
   alongside, never instead.
4. Residual limitation: two open days is a tiny sample, and the
   holiday itself may suppress Thursday–Friday demand (students away)
   — no frame fixes uncollected context.

**Where this class gets stuck.** Students average over seven days
(970/7 = 138.6) and conclude a catastrophic collapse — the fix is
naming the denominator before dividing. Second stall: believing one
frame is "the right one"; both are true, they answer different
questions, and the case is about choosing the frame that answers
*yours*.

## Five-minute teaching sequence

Minute 0–1 — **Read and analyse.** Expect the open-day count
questioned. Watch for: dividing by 7 on both weeks.
Minute 1–3 — **Develop an approach.** Expect both frames computed; a
correct per-open-day figure with totals missing is partial credit
(both belong in the answer). Watch for: averaging closed days as 0
into "typical" demand.
Minute 3–5 — **Compare and write.** Expect the verdict sentence and
the policy rule drafted.
Reveal and discuss — keep the reveal inside 10 minutes so the exit question still fits.

## Difficulty adaptation

- **Simplify.** Give the open-day counts (5 and 2) and ask only for
  the two averages and the direction of each frame's story.
- **Extend.** Ask for a week shape where per-open-day *also*
  misleads (a holiday that suppresses adjacent days' demand), and
  what extra data would expose it.
- **Hints (progressive).**
  1. *Re-orient:* "How many days was the library actually open in
     each week?"
  2. *Structure:* "Totals first, then per-open-day; report both with
     their denominators."
  3. *Near-answer:* the common wrong turn is the seven-day
     denominator — undo that choice and re-derive the step it breaks.

## Reference solution (pseudocode)

```
total_frame  <- sum(visits) vs sum(visits2)
open_frame   <- sum(visits)/open_days  vs  sum(visits2)/open_days2
verdict      <- open_frame answers demand; total_frame answers load
policy_rule  <- when calendars differ, compare like-for-like first
```

## Reference solution (Python)

```python
SURVEY = [520, 540, 500, 530, 510]
HOLIDAY = [0, 0, 0, 490, 480]

def frames(week, other):
    t1, t2 = sum(week), sum(other)
    d1 = sum(1 for v in week if v > 0)
    d2 = sum(1 for v in other if v > 0)
    return t1, t2, t1 / d1, t2 / d2

if __name__ == "__main__":
    t1, t2, a1, a2 = frames(SURVEY, HOLIDAY)
    print(f"totals {t1} vs {t2} ({(t2 - t1) / t1:+.1%})")
    print(f"per-open-day {a1:.0f} vs {a2:.0f} ({(a2 - a1) / a1:+.1%})")
```

The code is runnable as-is; executing the file prints the worked instance
so you can demo it live on the projector.

## Edge cases

- A week with zero open days — per-open-day undefined; the policy
  must say what prints.
- A partial-day closure (half day) — denominator becomes
  fractional; state the convention (count 0.5) before using it.
- Visits logged but doors closed (card-reader error) — the frame
  needs a data-quality check before any division.

## Alternative approaches

- Report totals only with a holiday footnote — honest about load,
  silent on demand; acceptable for operations, not for the survey
  question.
- Compare only Thursday–Friday (the matched pair) — narrow but
  clean; two days is thin evidence, worth computing: 520 vs 485, the
  same −6.7% as the open-day frame here because the survey week's
  five days were unusually uniform — worth noticing in itself.
- Weighted per-open-day with expected holiday demand — the grown-up
  version; needs an estimate the library does not have.
- **Cost.** All frames are O(n) arithmetic; the cost that matters is
  reputational — publishing −63% without the frame note.

## Common pitfalls

- Dividing weekly totals by 7 for "average daily".
- Reporting the per-open-day frame without the totals (hides the
  operational load).
- Using the frame that supports the pre-chosen story.
- No caveat about what two open days can and cannot show.

## Reveal script

1. Display the case and start the timer (5 minutes). While students work,
   circulate and read shoulders; pick one conventional attempt and one
   surprising one for the board.
2. Ask first: "How many days was the library open in each week?"
3. Compute both frames on the board; write each frame's *question*
   above it.
4. Surface the wrong turn directly: the 970/7 average — ask what that
   number claims about a closed door.
5. Show the reference Python, run it on the worked instance, and let the
   class compare with their own answers.
6. Close by naming the technique — "choose the denominator before the
   division" — and hand over the discussion prompt about the caveat.

## Assessment use

- **Formative use.** discussion-grade: mark frame awareness and
  denominator discipline over the percentages.
- **Mini-rubric (10 points).**
  - *Structure (2):* both frames named with their questions.
  - *Method (3):* per-open-day computed on open days only; totals
    kept.
  - *Result (3):* 2600 vs 970 and 520 vs 485 with signed percentages.
  - *Communication (2):* verdict cites the like-for-like rule;
    limitation named.
- **Follow-up check.** Holiday also covers Friday: what does each
  frame now say, and which staff proposal survives?
